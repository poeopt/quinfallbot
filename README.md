# Инструкция по использованию Quinfall Bot

## 1. Подготовка системы (Windows)
Для того чтобы бот мог перехватывать пакеты без сторонних прокси, необходимо:
1.  **Установить Npcap**: Скачайте и установите [Npcap](https://npcap.com/#download). При установке выберите опцию "Install Npcap in WinPcap API-compatible Mode".
2.  **Установить Tesseract OCR**: Если вы планируете использовать визуальную проверку (OCR), установите [Tesseract](https://github.com/UB-Mannheim/tesseract/wiki).
3.  **Права администратора**: Бот должен быть запущен от имени администратора, чтобы иметь доступ к сетевому интерфейсу.

## 2. Установка зависимостей
Запустите команду в терминале:
```bash
pip install -r requirements.txt
```

## 3. Настройка
Все настройки находятся в файле `src/config.py`.
- `GAME_SERVER_PORT`: Если вы знаете порт сервера игры (например, 8081), укажите его для ускорения работы.
- `TESSERACT_PATH`: Укажите путь к установленному `tesseract.exe`.

## 4. Запуск бота
```bash
python bot_core.py
```

## 5. Сборка в EXE
Для создания одного файла `.exe`, запустите:
```bash
python build_bot.py
```
Готовый файл появится в папке `dist/`.

## 6. Управление
- **START BOT**: Запускает перехват пакетов.
- **RECORD ROUTE**: Включает режим записи вашего пути. Бот будет сохранять координаты каждые несколько метров.
- **SAVE ROUTE**: Сохраняет записанный путь в файл `custom_route.json`.
- **LOAD ROUTE**: Загружает маршрут для отображения или следования.
